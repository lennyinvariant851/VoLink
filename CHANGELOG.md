# Changelog

## 1.0.0 — 2026-08-11

First public release of the Windows 4G/5G modem control center.

### Highlights

- Automatic Windows modem and AT-port discovery
- SIM, signal, operator, IMEI, IMSI, ICCID and firmware status
- Direct dialing, hangup and local call history
- SMS, AT terminal and USSD
- eSIM lifecycle through lpac
- HTTP and SOCKS5 proxy instances
- Telegram, Feishu, QQ Bot, Bark, Email, PushPlus and Webhook notifications
- VoHive-style device workspace

### Tested hardware

- Sierra Wireless EM7430 on COM17

### Download notes

The release asset is an unsigned portable Windows x64 executable. SmartScreen may display an unknown-publisher warning. Voice audio and eSIM depend on modem firmware and hardware capabilities.
