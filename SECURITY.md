# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository.

Do not include real SIM identifiers, phone numbers, eSIM activation codes, bot tokens, SMTP passwords or proxy credentials in reports.

## Local data

VoLink stores settings and operational records in the Electron user-data directory on the local Windows account. Notification credentials are currently stored locally and are not uploaded by VoLink. Protect the Windows account and avoid sharing the runtime data file.
